# PROJECT 6 – STUDENT FEEDBACK SENTIMENT SCORING

## About the Project
The Student Feedback Sentiment Scoring project is designed to analyze student feedback and identify whether it is positive, negative, or neutral. It uses predefined positive and negative words to evaluate the feedback. Based on the number of positive and negative words, it calculates a sentiment score and displays the overall feedback result.

## Technologies Used
- **Python** – Used to develop the sentiment analysis program.
- **Strings** – Used to accept and process student feedback.
- **Lists** – Used to store positive and negative words.
- **Loops** – Used to check words in the feedback.
- **Conditional Statements** – Used to classify the feedback.
- **String Methods** – Used to convert and process text.

## Main Features
- Accepts feedback from students.
- Identifies positive words in the feedback.
- Identifies negative words in the feedback.
- Counts positive and negative words.
- Calculates the sentiment score.
- Classifies feedback as Positive, Negative, or Neutral.
- Displays a feedback analysis report.

## Algorithm
1. Start the program.
2. Accept feedback from the student.
3. Convert the feedback into lowercase.
4. Split the feedback into individual words.
5. Define lists of positive and negative words.
6. Check each feedback word against both lists.
7. Count the positive and negative words.
8. Calculate the sentiment score.
9. Determine whether the feedback is Positive, Negative, or Neutral.
10. Display the sentiment analysis report.
11. Stop the program.

## Sample Output
```text
Enter student feedback: The teaching is good and excellent

----- STUDENT FEEDBACK REPORT -----

Positive Words Count: 2
Negative Words Count: 0
Sentiment Score: 2

Overall Feedback: Positive
```

## Conclusion
This project helps analyze student feedback and understand their opinions using basic sentiment analysis techniques. It demonstrates Python concepts such as strings, lists, loops, conditional statements, and string methods.
